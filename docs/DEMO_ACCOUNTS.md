# VoteTune Demo Accounts

The following seeded accounts are available for testing role-based access control and dashboard functionality.
Password for all accounts is `password`.

## Administrator
- **Email:** admin@votetune.com
- **Role:** Administrator
- **Capabilities:** Access to the Admin dashboard, managing system settings, viewing platform statistics.

## Host
- **Email:** host@votetune.com
- **Role:** Host
- **Capabilities:** Access to the Host dashboard, creating rooms, managing live queues.

## User
- **Email:** user@votetune.com
- **Role:** User
- **Capabilities:** Access to the standard User dashboard, joining rooms, voting on songs.
